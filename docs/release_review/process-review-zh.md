## 通用原则提炼

1. **一次收尾，全量核对**：草稿/文档任何变更后跑"一致性检查"（版本、链接、字符数、清单），不拆分到多个 PR。
2. **认证边界先声明**：第三方平台编辑 = 维护者人工；自动化只读公开视图。
3. **包可自证**：分发物必须带独立明文标识（version.txt），核验不依赖 DLL 反读。
4. **教训进 runbook**：每次事故落一条可执行检查项，不留在 Claim Pack 里沉底。
