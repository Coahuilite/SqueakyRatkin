# 0.3.0 内核等价评审与设置全项审计（对等实现替换验收记录）

> 状态：0.3.0 实施产物，随提交入库；是 0.3.1 切核回放的对照基线。
> 依据：决策文档 §5「0.3.0 设置全项等价验证」+ §4.1/§4.2/§4.6。
> 第一原则（全窗口适用）：已发布功能 = 玩家可能使用 → 设置全项验证；唯一豁免 = dev 隐藏功能。

## 1. 评审范围与方法

- **换面项（被内核化）**：`voicePackMode`、`voicePackSelections`（选择→池成员）、隐式 vanilla 兜底（→内置表）、playability/pawn 身份/Rand（→ISoundGate/IRollSource 注入）。
- **对照基准**：旧实现 `SqueakRuntimeSnapshot.Choose`/`ChoosePack`/`Choice`/`ResolvedAudioPack`/`GetSelected`/`GetVanilla`（v0.2.4 tag，本分支与 tag 零差异已核验）。
- **新实现**：`SqueakPoolRegistry.Select`（Kernel/，零 Verse 引用，纯度门由 KernelCharacterization 链接编译强制）。
- **证据三层**：① 语义规范逐条对照（本文档）② 黄金语料全场景矩阵（`fixtures/corpus/corpus-0.3.0.txt`，1622 例，生成+回放零 delta）③ 分布与实机（单测直方图有界断言 + 发布门槛 C 面实机快照，后置）。

## 3. 设置全项映射审计（换面/不换面 + dev 豁免）

**换面项（4 项，语料矩阵覆盖）**：

| 设置/输入 | 旧实现 | 内核承接 | 证据 |
| --- | --- | --- | --- |
| `voicePackMode` | Off/Fallback/Remix 三分支（Choose） | Select mode 三分支 | 语料三模式全场景 + 单测链回退序 |
| `voicePackSelections` | selection keys → 池成员（GetSelected） | 适配层投影 → VoicePackEntry → 域池 | 语料 S1-S5 选择状态矩阵 |
| 隐式 vanilla 兜底 | C# 字典 `SR_*` → SoundDef | 内置表种子 = AudioKey | 单测 15 键逐 action + Off 场景 |
| playability/clip/身份/Rand | HasPlayable→Rand.Range | ISoundGate/IRollSource 同一实例 | 语料 all/partial 两面 + 分布直方图 |

**不换面项（原地，零语义改动审计）**：`globalActionEnabled`/scope、`xenotypePresets`（行为/mood delta 构建，resolver `BuildBehavior`/`BuildContext` 不动）、`moodOverrides`（Comp `ResolveMoodMod`）、`scaleCooldownWithTimeSpeed`/`globalCooldownMultiplier`/启动相位（TimingModel）、`scaleFrequencyWithTalking`/vocal、`scalePeriodicWithAudiblePopulation`、`distancePreset`/`distanceRange`（`ApplyDistanceRange`）、`voicePackSchemaVersion`/`settingsSchemaVersion`（序列化面，0.3.0 不 bump 不迁移）。

**dev 隐藏功能豁免（唯一豁免，不占验证门）**：`developerToolsEnabled`、`devLoggingMode`、`localizeDebugActions` 及七次点击解锁面——隐藏内容、非公开承诺面，坏了由维护者自行发现。

## 4. 已知差异与边界（诚实声明）

1. **非"同 seed 逐项对拍"**：旧 `Rand.Range` 与内核 `floor(Next01()*N)` 分布等价但逐次抽取不同；玩家承诺 = 同池同分布（0.2.x 本就随机），语料按新 roll 序列固化（自洽基线）。若需逐项对拍须双实现（方案 D，已否）。
2. **池排序差异面**：旧 `GetSelected` 只对选中 pack 排序；内核 DomainPool 对所有注入条目排序——0.3.0 注入面 = 旧选择面，无行为差异；`PoolStableKey` 语义一致。
3. **0.3.0 不启用**：年龄优先级、pack fallback、带权（Weight≠1）、`ClassifyDomainStatus` 完整接线（0.3.1/0.3.2）；类型与纯逻辑已入库，未接线不构成行为面。

## 5. 结论

换面项 4 项语义逐条承接（§2 表 14 行全部等价判定）；不换面项零改动审计通过；dev 豁免单列。黄金语料 1622 例生成 + 回放零 delta（C4 提交）。0.3.1 切核以本文档 + 语料为回归基线；任何语料 delta = 回归，先查实现后查场景构造（Scenarios.cs 冻结，不得改动）。
